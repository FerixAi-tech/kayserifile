# Kayseri File

Kayseri'de balkon filesi, kuş filesi, halı saha filesi ve inşaat filesi montajı için tanıtım sitesi.

## Çalıştırma

```bash
npm install
npm run dev
```

## İletişim bilgileri

WhatsApp ve telefonu `.env.local` dosyasına yazın:

```
NEXT_PUBLIC_PHONE=0532 000 00 00
NEXT_PUBLIC_WHATSAPP=905320000000
NEXT_PUBLIC_EMAIL=info@kayserifile.com
```

WhatsApp numarası ülke koduyla, başında 0 olmadan yazılır.
